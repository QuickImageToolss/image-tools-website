How to use this tool

  1. Select an image from your device.
  2. Review the preview and choose the available settings.
  3. Press Process Image and wait for the result.
  4. Download the processed image and check it before use.

Privacy and image quality

Processing happens in your browser. Your selected image is not uploaded to our server for processing. Keep the original file because resizing, cropping or format conversion can change image dimensions, quality, transparency or file size.

Understanding image width and height

Image dimensions are measured in pixels. Width describes how many pixels run from left to right, while height describes how many pixels run from top to bottom. This resizer starts with the image's original dimensions in the input fields so you can see its current size before making a change.

Keep the original proportions

Enter a width and height that match the shape of your image. If the new width-to-height ratio is different from the original, the image may look stretched or squashed. This tool uses the exact dimensions you enter; it does not automatically calculate a matching height. If you are unsure, compare the original and resized previews and try dimensions with the same ratio.

When should you resize an image?

Resizing can help prepare an image for a website, presentation, document or profile that requires particular pixel dimensions. Reducing dimensions can also reduce file size, although the final size depends on the image and output format. Increasing dimensions does not create genuine detail that was not present in the original image.

Output format and quality

The resized result is saved as a JPG image. JPG is suitable for many photographs, but it does not preserve transparent areas and can introduce compression changes. Transparent parts of an input image are filled with white in the JPG result. Check the saved file before using it in a design that needs transparency.

Common problems

Both dimensions must be whole numbers between 1 and 12,000 pixels. If processing does not complete, try a smaller image or lower dimensions, and make sure your browser has enough available memory. The original file is not changed; download the result separately and keep your source image.
